# 셀러·푸드트럭 섭외 풀 (Seller Pool)

플릿 유니온이 행사에 섭외할 수 있는 셀러·푸드트럭 후보를 한곳에 모아 관리하는 명단입니다.
`seller-pool.csv` 를 노션으로 가져와 데이터베이스로 쓰고, 이 저장소의 CSV는 백업본으로 둡니다.

---

## 노션으로 가져오기

1. 노션에서 새 페이지를 만들고 좌측 하단 **가져오기(Import)** → **CSV** 선택
2. `seller-pool.csv` 업로드 → 데이터베이스가 자동 생성됩니다
3. CSV 로 가져오면 모든 속성이 **텍스트**로 들어옵니다. 아래 표대로 속성 유형을 바꿔주십시오

## 만들어 두면 좋은 보기(View)

| 보기 이름 | 필터 | 용도 |
|---|---|---|
| 전체 | 없음 | 기본 |
| 푸드트럭 | 구분 = 푸드트럭, 푸드트럭 대행사 | 푸드트럭 섭외 시 |
| 플리마켓 셀러 | 구분 = 셀러 | 마켓 셀러 섭외 시 |

## 운영 규칙

- **연락처와 담당자는 노션에만 적습니다.** 이 저장소의 CSV에는 넣지 않습니다.
- **웹 조사로 채운 항목은 아직 "후보"입니다.** 실제 연락해 참가 의사를 확인한 뒤에야
  `컨택완료` 로 바꿉니다. 제안서나 외부 자료에 넣을 수 있는 것은 `참가이력` 이 있는 곳뿐입니다.
- 외부에 명단을 공유할 때는 **업체명 없이 카테고리·지역·규모만** 내보내는 것을 원칙으로 합니다.
  업체명을 공개하려면 해당 업체의 동의를 받아야 합니다.
- 푸드트럭은 섭외 확정 전 **영업허가증과 위생 점검 이력**을 반드시 확인하고 `영업허가·위생` 을 갱신합니다.
