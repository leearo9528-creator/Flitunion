# 셀러 품목 사진

`docs/catalog-build.js` 가 이 폴더에서 사진을 찾아 셀러 품목 카탈로그에 넣습니다.
파일명이 곧 자리 지정입니다. 확장자는 `jpg` / `jpeg` / `png` / `webp` 모두 됩니다.

```bash
node docs/catalog-build.js   # pptxgenjs 필요 (npm i pptxgenjs)
```

**현재 30자리 전부 비어 있습니다.** 사진을 넣기 전까지는 '사진 준비 중' 자리표시로 나갑니다.

## 사진 어디서 구하나

카탈로그는 **품목 단위**라 특정 셀러의 상품일 필요가 없습니다. 그 품목이 어떤 것인지
보여주기만 하면 됩니다. 구할 수 있는 순서는 이렇습니다.

1. **현장 스케치 사진** — 우리가 운영한 행사에서 찍은 부스·상품 사진이 가장 좋습니다. 저작권 문제가 없습니다.
2. **셀러에게 요청** — 노션 연락망에서 해당 품목 셀러에게 상품 사진을 요청합니다. 카탈로그에 쓰겠다고 밝히고 동의를 받으십시오.
3. **셀러 인스타그램** — 무단 사용은 안 됩니다. 반드시 사전 동의를 받고 가져오십시오.

⚠️ **웹에서 검색해 나온 사진을 그대로 쓰면 안 됩니다.** 외부 배포용 자료라 저작권 분쟁 소지가 있습니다.

## 사진 규격

- **정사각형(1:1)** 권장. 가로세로 비가 1.25 를 넘으면 자르지 않고 흰 여백을 채워 넣습니다.
- 한 변 **900px 이상**이면 충분합니다.
- 사람 얼굴이 크게 나온 사진은 외부 배포용이므로 피하시거나 사전 동의를 받아주십시오.
