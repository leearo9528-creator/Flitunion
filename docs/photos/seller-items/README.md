# 셀러 품목 사진

`docs/catalog-build.js` 가 이 폴더에서 사진을 찾아 셀러 품목 카탈로그에 넣습니다.
파일명이 곧 자리 지정입니다. 확장자는 `jpg` / `jpeg` / `png` / `webp` 모두 됩니다.

```bash
node docs/catalog-build.js   # pptxgenjs 필요 (npm i pptxgenjs)
```

---

## ⚠️ 지금 들어가 있는 사진은 예시 이미지입니다

27장 전부 **자유 이용 라이선스(CC0 · 퍼블릭도메인) 스톡 사진**입니다.
저작권상 상업적 사용에 문제가 없어 외부 배포본에 그대로 넣어도 됩니다.

다만 **우리 셀러가 실제로 파는 상품 사진이 아닙니다.** 품목이 어떤 것인지 보여주는 용도입니다.
그래서 카탈로그 하단에 그 사실을 명시해 뒀습니다. 이 문구를 지우고 배포하면 안 됩니다.

출처·라이선스 내역은 `CREDITS.json` 에 슬러그별로 기록돼 있습니다.

**실제 셀러 사진으로 교체하는 것이 최종 목표입니다.** 같은 파일명으로 덮어쓰면 카탈로그가 자동 갱신됩니다.
구할 수 있는 순서는 이렇습니다.

1. **현장 스케치 사진** — 우리가 운영한 행사에서 찍은 부스·상품 사진. 저작권 문제가 없습니다
2. **셀러에게 요청** — 노션 연락망에서 해당 품목 셀러에게 요청. 카탈로그에 쓰겠다고 밝히고 동의를 받으십시오
3. **셀러 인스타그램** — 반드시 사전 동의를 받고 가져오십시오

⚠️ 웹에서 검색해 나온 사진을 그대로 쓰면 안 됩니다. 외부 배포용이라 저작권 분쟁 소지가 있습니다.

## 사진 규격

- **정사각형(1:1)** 권장. 가로세로 비가 1.25 를 넘으면 자르지 않고 흰 여백을 채워 넣습니다.
- 한 변 **900px 이상**이면 충분합니다.
- 사람 얼굴이 크게 나온 사진은 외부 배포용이므로 피하시거나 사전 동의를 받아주십시오.
