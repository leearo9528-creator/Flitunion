## 플릿 소개서 구성 (17장, 16:9 13.33×7.5in)

표지 → 목차 → 회사 개요(기업 정보 + 핵심 수치 4종) → 비전·미션 → 고객의 과제와 해법 → 사업 영역 4종 → 서비스 상세 4장 → 차별점(플릿 플랫폼 + 일반 모집 비교표) → 운영 프로세스 5단계 → 주요 실적 8건 → 사례 연구 2건 → 협업 대상 → 계약·운영 안내 → Contact

- 톤: 포멀 격식체("~합니다/~드립니다")
- 색: 파란 배경(네이비 `0B1F44` / 브랜드 `3182F6`) + 흰색 카드·텍스트
- 본문 폰트: 맑은 고딕, 워드마크: Arial Black
- 모든 수치·문구는 flitunion.com 사이트(`src/data/services.ts`, `portfolio.ts`, 각 섹션 카피)에서 가져옴. 대표자·설립일·사업자번호는 사이트에 없어 미기재 — 추가 시 3p '기업 정보' 카드에 행 추가
