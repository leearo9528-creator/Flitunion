# 상품 구조 & 가격표

> 원가는 실제 단가 기준 (2026-08 확정): 텐트 5만/동 · 테이블 2만/개 · 의자 2천/개 · 인력 20만/인 · 홍보 30만.
> 가격 조정 규칙: 두 건 연속 즉답 수락 → 다음 견적 +20%. 거절 → 이유를 CRM에 기록 (비쌈 / 시기 / 불신).

## 0. 원가표 — 기준 행사 (부스 20개)

구성: 텐트 10동(2부스/동) + 테이블 20개 + 의자 20개

| 항목 | 계산 | 금액 |
|---|---|---|
| 텐트 | 10동 × 50,000 | 500,000 |
| 테이블 | 20개 × 20,000 | 400,000 |
| 의자 | 20개 × 2,000 | 40,000 |
| 현장 인력 | 1인 × 200,000 (야간·대형은 2인) | 200,000~400,000 |
| 홍보 | 고정 | 300,000 |
| **합계** | | **1,440,000 (1인) / 1,640,000 (2인)** |

- **부스당 장비 원가 47,000원 · 풀대행 총원가 부스당 72,000~82,000원**
- 장기 과제: 텐트 구매 전환 시(약 15만/동, 10회 상각) 회당 장비비 절반 이하로 하락

## 1. 고객은 두 종류다

| | 파트너형 고객 | 의뢰형 고객 |
|---|---|---|
| 누구 | 공간은 있는데 돈 쓰기 싫은 곳 (대학, 아파트, 상점가) | 돈 내고 맡기고 싶은 곳 (기업, 기획사, 예산 있는 기관, 개인) |
| 과금 | **별도 협의** (내부 가드레일은 §2 ③-b) | 정액 용역비 + 착수금 |
| 기획서 | 01-마스터 템플릿 (기존) | 아래 상품 메뉴 + 견적서 |

**같은 기획서에 두 구조를 섞지 않는다.** 상대가 어느 쪽인지 첫 통화에서 판별하고 한 가지만 제안한다.

## 2. 상품 메뉴 (의뢰형)

### ① 기획 패키지 — 진입 상품 (박리 전략)
- **산출물**: 행사 기획안 + 부스 배치 도면(실측 기반) + 당일 운영 매뉴얼 + 셀러 모집 공고문 세트
- **가격**: **290,000원** (부스 15개 이하 소형: 190,000원)
- **결제**: 계약 시 100% 선불 → 납품으로 종료
- **역할**: 이익 상품이 아니라 **문턱 상품**이다. "일단 29만으로 기획만 받아보세요" → ②③ 전환이 목적. 원가가 시간뿐이므로 박리가 가능하다.
- **경계선 (가격이 낮아진 만큼 더 엄격하게, 계약서 명기)**:
  - 수정 **1회** 포함, 이후 회당 55,000원
  - 현장 답사 1회 포함, 행사 당일 출동 미포함
  - 납품 후 14일 경과 시 문의 대응 종료
  - 셀러 모집·운영·장비 미포함 (업그레이드 시 기지불액 전액 공제)

### ② 부분 대행 — 주력 상품 (기획 + 셀러 모집, 장비·현장 미포함)
- **산출물**: ① 전체 + 셀러 모집·심사·확정 + 배치 확정본 + 셀러 안내문 발송
- **가격**: **290,000원 + 부스당 50,000원** (예: 20부스 = 1,290,000원)
- **결제**: 계약 시 50% / 셀러 확정 납품 시 50%
- **경계선**: 행사 당일 운영·안전 관리는 의뢰인 몫임을 명기. 당일 유선 자문은 포함.
- **장비가 필요하면 → 아래 렌탈 옵션을 별도 견적으로 붙인다.**

### ⊕ 장비 렌탈 옵션 — 별도 상품 (②에 붙이거나 단독 판매)
| 항목 | 가격 | 원가 | 비고 |
|---|---|---|---|
| 기본 세트 (텐트 ½동 + 테이블 1 + 의자 1) | **부스당 70,000원** | 47,000 | 마진 33% |
| 설치·수거 인력 | 회당 200,000원 | 200,000 | 실비. 규모 커지면 2인 |
| 예시: 20부스 풀장비 | 1,400,000 + 200,000 = **1,600,000** | 1,140,000 | 이익 46만 |

- ② + 장비 옵션 (20부스) = 129만 + 160만 = **289만** → ③ 풀대행(300만)과 11만 차이. **"11만 더 내면 당일 운영까지 저희가 다 합니다"** 가 ③ 전환 멘트다.
- 단독 렌탈 문의(장비만)도 이 표로 견적한다.

### ③ 풀대행 — 전 과정 턴키 (장비·인력 포함)
- **산출물**: 기획~셀러~장비~현장 운영~철거~정산 보고까지 전부
- **정가**: **부스당 150,000원, 최소 계약 2,500,000원**
- **협상 하한**: 부스당 120,000원 — 이 밑으로는 견적하지 않는다 (원가 8.2만 × 1.5 방어선)
- **결제**: 계약 시 30% / 셀러 확정 시 40% / 행사 종료 후 30%
- **손익 (20부스 기준)**:
  | 견적 | 매출 | 원가(2인) | 이익 | 마진 |
  |---|---|---|---|---|
  | 정가 15만 | 300만 | 164만 | 136만 | 45% |
  | 하한 12만 | 240만 | 164만 | 76만 | 32% |

### ③-b 파트너형 — **별도 협의** (메뉴에 가격을 올리지 않는다)
- 대외적으로는 "공간 조건에 따라 별도 협의"로만 안내. 확정 배분율·참가비를 먼저 제시하지 않는다.
- **내부 가드레일 — 이 조건이 안 되면 딜을 열지 않는다**:
  1. 테이블·의자는 셀러 자가 지참 원칙 (장비비 94만 → 50만)
  2. 셀러 참가비 최소 100,000원/팀 (8만으로는 구조적 적자)
  3. 기관 배분율 상한 20%
- 근거: 참가비 8만 × 20부스 = 매출 160만 vs 원가 144~164만 → 배분 전부터 본전/적자
- 검증 (30부스 · 참가비 10만 · 셀러 지참 · 배분 20% · 인력 2인): 매출 300만 − 배분 60만 − 원가 145만 = **이익 95만**
- 협의 시 시작점: 배분율 10%에서 시작해 상한 20%까지만 양보. 소규모(20부스 이하)는 B형 역발상 — 기관 몫을 정액 소액으로 캡
- **포트폴리오가 쌓이는 건 ③과 ③-b뿐이다.** 초반엔 이 둘을 우선하고 ①은 문턱 상품으로 운용

## 3. 가격 운용 원칙

1. **부스 수로 과금한다.** 시간·일수 견적은 깎이기만 한다. 규모 커지면 가격이 자동으로 따라온다.
2. **사다리로 판다.** ① 29만(문턱) → ② 129만(주력) → ②+장비 289만 → ③ 300만(턴키). 각 단계 간격이 "조금만 더 내면"을 만든다.
3. **공개는 "~부터", 확정은 견적서로.** 기획서·웹사이트에는 "부스당 15만원부터"까지만. 장비 조건이 케이스마다 달라 고정가 공개는 손해다.
4. **할인 대신 옵션을 뺀다.** "비싸다" → 가격을 깎지 말고 부스 수·장비 사양을 줄인 안을 다시 견적한다. 하한선은 풀대행 부스당 12만, 장비 부스당 6만.
5. **업그레이드 경로를 항상 열어둔다.** ①→②→③ 전환 시 기지불액 전액 공제. 29만짜리 ① 고객이 ③으로 넘어오면 그게 최고 마케팅비 효율이다.

## 4. 착수금 · 취소 규정 (계약서 필수 조항)

| 취소 시점 | 착수금 처리 |
|---|---|
| D-30 이전 | 전액 환불 |
| D-29 ~ D-14 | 50% 환불 |
| D-13 이후 | 환불 불가 (셀러 모집·장비 발주가 이미 진행됨) |
| 우천 등 불가항력 | 예비일 이월 우선, 불가 시 실비 공제 후 환불 |

- 장비 렌탈 옵션은 D-3 이후 취소 시 전액 청구 (발주 완료 기준)
- 잔금 미지급 시 산출물 사용권 미이전 조항 포함

## 5. 첫 통화 판별 스크립트

> 30초 안에 파트너형/의뢰형을 가른다.

- "이번 행사에 **책정된 예산**이 있으실까요?"
  - 있다 → 의뢰형. "규모에 따라 부스당 15만원부터입니다" → 견적 상담
  - 없다/모르겠다 → 파트너형. "공간 조건 보고 별도 협의로 진행합니다" → 내부 가드레일 3조건 계산 → 통과 시에만 01-템플릿 발송
- "행사 당일 운영하실 인력이 있으신가요?"
  - 있다 → ①② (+장비 옵션) 제안 / 없다 → ③ 제안
- "장비(텐트·테이블)는 갖고 계신가요?"
  - 없다 → ② + 렌탈 옵션 견적을 ③과 나란히 제시 (11만 차이를 보여주며 ③ 유도)
