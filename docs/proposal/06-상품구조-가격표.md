# 상품 구조 & 가격표

> 원가는 실제 단가 기준 (2026-08 확정): 텐트 5만/동 · 테이블 2만/개 · 의자 2천/개 · 인력 20만/인 · 홍보 30만.
> 가격 조정 규칙: 두 건 연속 즉답 수락 → 다음 견적 +20%. 거절 → 이유를 CRM에 기록 (비쌈 / 시기 / 불신).

---

## 0. 원가표 — 기준 행사 (부스 20개)

구성: 텐트 10동(2부스/동) + 테이블 20개 + 의자 20개

| 항목 | 계산 | 금액 |
|---|---|---|
| 텐트 | 10동 × 50,000 | 500,000 |
| 테이블 | 20개 × 20,000 | 400,000 |
| 의자 | 20개 × 2,000 | 40,000 |
| 현장 인력 | 1인 × 200,000 (야간·대형은 2인) | 200,000~400,000 |
| 홍보 | 고정 | 300,000 |
| **합계** | | **1,440,000 (1인) / 1,640,000 (2인)** |

- **부스당 원가: 72,000~82,000원**
- 규모 환산: 부스 N개 ≒ 장비 47,000×N + 인력 + 홍보 30만
- 장기 과제: 텐트 구매 전환 시(약 15만/동, 10회 상각) 회당 장비비 절반 이하로 하락

## 1. 고객은 두 종류다

| | 파트너형 고객 | 의뢰형 고객 |
|---|---|---|
| 누구 | 공간은 있는데 돈 쓰기 싫은 곳 (대학, 아파트, 상점가) | 돈 내고 맡기고 싶은 곳 (기업, 기획사, 예산 있는 기관, 개인) |
| 과금 | 0원 + 수익 배분 | 정액 용역비 + 착수금 |
| 기획서 | 01-마스터 템플릿 (기존) | 아래 상품 메뉴 + 견적서 |

**같은 기획서에 두 구조를 섞지 않는다.** 상대가 어느 쪽인지 첫 통화에서 판별하고 한 가지만 제안한다.

## 2. 상품 메뉴 (의뢰형)

### ① 기획 패키지 — "가볍게 맡기고 싶은 분"
- **산출물**: 행사 기획안 + 부스 배치 도면(실측 기반) + 당일 운영 매뉴얼 + 셀러 모집 공고문 세트
- **가격**: **990,000원** (부스 15개 이하 소형: 660,000원)
- **결제**: 계약 시 100% 선불 → 납품으로 종료
- **경계선 (계약서 명기)**:
  - 수정 2회 포함, 이후 회당 110,000원
  - 현장 출동 미포함 (답사 1회는 포함)
  - 납품 후 14일 경과 시 문의 대응 종료
  - 셀러 모집·운영은 미포함 (필요 시 ②③으로 업그레이드, 기지불액 공제)

### ② 부분 대행 — "모집까지만 해주세요"
- **산출물**: ① 전체 + 셀러 모집·심사·확정 + 배치 확정본 + 셀러 안내문 발송
- **가격**: **990,000원 + 부스당 40,000원** (예: 20부스 = 1,790,000원)
- **결제**: 계약 시 50% / 셀러 확정 납품 시 50%
- **경계선**: 행사 당일 운영·장비·안전 관리는 의뢰인 몫임을 명기. 당일 유선 자문은 포함.

### ③ 풀대행 — 전 과정 턴키
- **산출물**: 기획~셀러~장비~현장 운영~철거~정산 보고까지 전부
- **정가**: **부스당 150,000원, 최소 계약 2,500,000원**
- **협상 하한**: 부스당 120,000원 — 이 밑으로는 견적하지 않는다 (원가 8.2만 × 1.5 방어선)
- **결제**: 계약 시 30% / 셀러 확정 시 40% / 행사 종료 후 30%
- **손익 (20부스 기준)**:
  | 견적 | 매출 | 원가(2인) | 이익 | 마진 |
  |---|---|---|---|---|
  | 정가 15만 | 300만 | 164만 | 136만 | 45% |
  | 하한 12만 | 240만 | 164만 | 76만 | 32% |

### ③-b 파트너형 (기존 모델) — ⚠ 성립 조건 필수 확인
- 의뢰인 부담 0원, 부스 참가비 수익 배분 (01-템플릿 8번 A~D 방식)

**적자 함정**: 참가비 8만 × 20부스 = 매출 160만 vs 원가 144~164만 → **배분 전부터 본전/적자.**
파트너형은 아래 3조건을 지켜야만 연다:

1. **테이블·의자는 셀러 자가 지참 원칙** — 장비비 94만 → 50만(텐트만). 가장 큰 레버
2. **참가비 최소 100,000원/팀** — 8만으로는 구조적으로 불성립
3. **기관 배분율 상한 20%** — 01-템플릿의 배분율 예시도 이 상한 안에서 제시할 것

검증 (30부스 · 참가비 10만 · 셀러 지참 · 배분 20% · 인력 2인):
매출 300만 − 배분 60만 − 원가 145만(텐트 15동 75 + 인력 40 + 홍보 30) = **이익 95만**

- 20부스 이하 소규모 파트너형은 텐트도 미제공(셀러 지참 or 옵션 판매)으로 설계하거나, B형(최소 보장액)을 역으로 활용해 기관 배분을 정액 소액으로 캡한다
- **포트폴리오가 쌓이는 건 ③과 ③-b뿐이다.** 초반엔 이 둘을 우선하고 ①은 캐파 없을 때 받는 서브 상품으로 운용

## 3. 가격 운용 원칙

1. **부스 수로 과금한다.** 시간·일수 견적은 깎이기만 한다. 규모 커지면 가격이 자동으로 따라온다.
2. **②가 주력 판매 상품이다.** ①은 문턱(진입), ③은 앵커(비교 기준). "기획만 99만 vs 179만이면 셀러까지"의 간격이 ②를 팔아준다.
3. **공개는 "~부터", 확정은 견적서로.** 기획서·웹사이트에는 "부스당 15만원부터"까지만. 장비 조건이 케이스마다 달라 고정가 공개는 손해다.
4. **할인 대신 옵션을 뺀다.** "비싸다" → 가격을 깎지 말고 부스 수·장비 사양을 줄인 안을 다시 견적한다. 같은 스펙 할인은 다음 고객 가격도 무너뜨린다. 하한선은 부스당 12만.
5. **업그레이드 경로를 항상 열어둔다.** ①→②→③ 전환 시 기지불액 전액 공제. "일단 기획만" 고객의 상당수가 운영까지 넘어온다.

## 4. 착수금 · 취소 규정 (계약서 필수 조항)

| 취소 시점 | 착수금 처리 |
|---|---|
| D-30 이전 | 전액 환불 |
| D-29 ~ D-14 | 50% 환불 |
| D-13 이후 | 환불 불가 (셀러 모집·장비 발주가 이미 진행됨) |
| 우천 등 불가항력 | 예비일 이월 우선, 불가 시 실비 공제 후 환불 |

- ①번(기획 패키지)은 착수 즉시 작업이 시작되므로 **작업 착수 후 환불 불가** 별도 명기
- 잔금 미지급 시 산출물 사용권 미이전 조항 포함

## 5. 첫 통화 판별 스크립트

> 30초 안에 파트너형/의뢰형을 가른다.

- "이번 행사에 **책정된 예산**이 있으실까요?"
  - 있다 → 의뢰형. "규모에 따라 부스당 15만원부터입니다" → 견적 상담
  - 없다/모르겠다 → 파트너형. "비용 없이 수익 배분으로 진행하는 구조가 있습니다" → 단, ③-b 3조건 충족 여부 먼저 계산 → 01-템플릿 발송
- "행사 당일 운영하실 인력이 있으신가요?"
  - 있다 → ①② 제안 / 없다 → ③ 제안
