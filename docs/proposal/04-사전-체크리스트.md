# 사전 체크리스트

## Ⅰ. 기획서 쓰기 전 — 정보 수집 (최소 30분 투자)

### 필수 (없으면 쓰지 마라)
- [ ] **결정권자 파악**: 학생회? 학생처? 입대의? 원장? — 수신자에 따라 템플릿 변형이 달라진다
- [ ] **담당자 이름 또는 직함**: "담당자님께"보다 "축제기획국장님께"
- [ ] **현장 관찰 1개 이상**: 직접 방문 > 로드뷰 > 인스타/블로그 > 기사. 3번 섹션의 재료
- [ ] **공간 스펙 추정**: 대략의 크기(로드뷰로 측정 가능), 바닥 상태, 전기 유무
- [ ] **시즌·데드라인**: 축제일, 입대의 회의일, 방학 일정 → 역산해서 "지금이 적기" 근거 확보

### 있으면 강력
- [ ] 작년 행사 후기 (에브리타임, 인스타 해시태그, 맘카페, 지역 커뮤니티)
- [ ] 상대의 최근 고민 (공지사항, 뉴스, 민원 이슈)
- [ ] 소개해 줄 수 있는 연결 고리 (지인, 이전 거래처, 같은 지역 레퍼런스)

## Ⅱ. 기획서 완성 후 — 발송 전 최종 점검

### 내용
- [ ] `[[ ]]` 가 하나도 안 남았는가 — **Ctrl+F로 "[[" 검색 필수**
- [ ] 작성 지침 인용문(>)을 전부 지웠는가
- [ ] 1페이지만 읽어도 "부담 0원 + 수익 배분 + 미팅 요청"이 다 보이는가
- [ ] 3번에 이 공간에만 해당하는 문장이 2개 이상 있는가 (다른 기관명 넣으면 말이 안 되는 문장인가)
- [ ] 요청사항이 딱 1개인가
- [ ] 숫자에 근거 없는 과장이 없는가 (미팅에서 답할 수 있는 숫자만)
- [ ] 이전 기관명이 남아있지 않은가 — **치명적. 다른 기관명 전체 검색**

### 형식
- [ ] PDF로 변환했는가 (편집 가능한 파일 금지)
- [ ] 파일명: `플릿유니온_제안서_○○대학교_20260901.pdf`
- [ ] 용량 10MB 이하 (사진 압축)
- [ ] 휴대폰에서 열어봤는가 (담당자 절반은 폰으로 처음 연다)
- [ ] 연락처·홈페이지 링크가 살아있는가

### 발송
- [ ] 제목에 [기관명]이 들어갔는가
- [ ] 본문 관찰 문장이 이 기관 전용인가
- [ ] 미팅 가능 일자를 2~3개 구체적으로 제시했는가
- [ ] CRM 시트에 기록했는가 (D+4, D+10 후속 날짜 포함)
