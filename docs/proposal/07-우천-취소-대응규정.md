# 우천·취소 대응 규정

> 원칙: 비는 예외가 아니라 기본 설계 대상이다. 봄가을 주말 강수 확률은 20~30% — 10건 중 2~3건은 만난다.
> 분쟁은 비 때문이 아니라 **규정이 없어서** 생긴다. 아래 조항을 셀러 공고문·의뢰 계약서·파트너 협약서 3곳에 처음부터 박는다.

---

## 1. 판단 기준 (확정)

**기준 예보: 행사 전날 18:00 기상청 예보, 행사 시간대 강수량**

| 전날 18시 예보 | 판단 | 통보 |
|---|---|---|
| **5mm 이상 (강한 비)** | **취소(순연) 확정** | 전날 18시 즉시 전원 통보 |
| **1~5mm (약한 비)** | **보류 → 당일 아침 재판단** | 전날 18시 "보류" 공지 → **당일 08:00까지 최종 확정 통보** (행사 시작이 이르면 시작 6시간 전) |
| 1mm 미만 | 강행 | 별도 통보 없음 (예정대로) |

**기본 기조: 웬만하면 텐트 강행.** 전 부스 텐트 구조라 약한 비는 행사가 성립한다.
→ 영업 멘트로도 쓴다: "저희는 전 부스 텐트 운영이라 웬만한 비에는 정상 진행됩니다."

### ⚠ 강수와 무관한 취소 조건 (안전)
- **평균 풍속 10m/s(순간 15m/s) 이상 예보 또는 강풍·호우 특보 발효 시: 강수량 무관 취소**
- 텐트는 비가 아니라 **바람에 넘어진다.** 강풍 강행은 전도 사고 = 사업 끝. 이 기준만은 협상 불가.

---

## 2. 취소 시 대응 순서

1. **텐트 강행** (1~5mm 약한 비) — 기본값
2. **예비일 이월** — 계약 시점에 예비일을 미리 지정한다 (본행사 1~2주 뒤 같은 요일). 사후 협의 금지
3. **완전 취소** — 예비일마저 불가할 때만

---

## 3. 취소 시 돈 흐름

| 돈 | 규정 |
|---|---|
| 셀러 참가비 | **차회 이월 크레딧 기본, 요청 시 전액 환불** — 이월 유도로 현금 유출 방지 + 차회 셀러 확보 |
| 의뢰형 대금 (②③) | 수행 완료분(착수금+중도금)은 유지, **당일 운영분(잔금 30%)만 이월 또는 환불** |
| 장비 위약금 | 렌탈 업체 취소 규정(통상 D-3 이후 위약금)을 확인하고 **동일 조건으로 상위 계약서에 전가** (back-to-back). 전가 누락분 = 내 손실 |
| 파트너형 | 선투입 비용을 우리가 지는 유일한 구조 → **예비일 지정이 계약 필수 조건.** 실내·반실내 공간(로비·지하상가·주차타워) 딜을 우선한다 |

- 건당 매출 500만 이상 대형 행사부터는 강수량 연계 행사취소 보험(날씨 보험) 견적을 검토한다.

## 4. 복붙용 조항

### A. 셀러 모집 공고문용
```
[우천 안내]
· 본 행사는 전 부스 텐트로 운영되어 약한 비(1~5mm)에는 정상 진행됩니다.
· 행사 전일 18시 기상청 예보 기준 강수량 5mm 이상 예보 시 행사는
  예비일(0월 0일)로 순연되며, 전일 18시까지 전원 개별 통보드립니다.
· 약한 비(1~5mm) 예보 시에는 "진행 보류"로 안내드리고, 행사 당일
  오전 8시까지 진행 여부를 최종 통보드립니다.
· 순연·취소 시 참가비는 차회 행사 참가 크레딧으로 이월되며,
  원하시는 경우 3영업일 내 전액 환불됩니다.
```

### B. 의뢰 계약서용 (②③ 의뢰형)
```
제○조 (우천 등 기상 사유)
① 행사 전일 18시 기상청 예보 기준 행사 시간대 강수량 5mm 이상,
   평균 풍속 10m/s 이상 또는 기상특보 발효가 예상되는 경우
   행사는 쌍방 협의 없이 본 계약에서 정한 예비일(0월 0일)로 순연된다.
② 강수량 1~5mm 예보 시 행사 당일 오전 8시까지 "을"이 진행 여부를
   판단하여 통보하며, 텐트 설치 기반 정상 진행을 원칙으로 한다.
③ 순연 시 기지급 대금은 예비일 행사에 그대로 승계된다.
④ 예비일에도 제1항의 사유가 발생하여 행사가 최종 취소되는 경우,
   "을"이 기 수행한 업무(기획·모집 등)에 해당하는 대금은 반환하지
   아니하며, 미수행 업무분(당일 운영비)은 7영업일 내 반환한다.
⑤ 제1항의 판단 이후 발주된 장비의 취소 위약금은 "갑"이 부담한다.
```

### C. 파트너 협약서용 (③-b)
```
제○조 (우천 대비)
① 본 행사의 예비일은 0월 0일로 하며, 공간 제공자는 예비일의
   공간 사용을 본 협약으로써 함께 승인한다.
② 기상 사유 판단 기준 및 절차는 제○조(의뢰 계약서 B안 ①②항과 동일)를 따른다.
③ 예비일에도 행사가 불가한 경우 본 협약은 종료되며,
   쌍방은 상대방에게 비용·손해를 청구하지 아니한다.
```

## 5. 우천 강행 시 현장 체크리스트

- [ ] 텐트 전 동 **무게추/워터백** 고정 (강풍 대비, 미고정 텐트는 개장 불가)
- [ ] 전기 분배기·멀티탭 **방수 커버 + 지면 이격** (누전 = 최대 사고 리스크)
- [ ] 통행로 배수 확인, 미끄럼 구간 매트/안내판
- [ ] 셀러 물품 바닥 이격용 팔레트/깔판 여분
- [ ] 우천 시 축소 운영 안 (부스 통합·시간 단축) 사전 준비
