# 아웃리치 스크립트 (DM · 메일 · 후속)

> 원칙 3가지
> 1. **첫 메시지에서 팔지 않는다.** 기획서를 열게 만들고, 미팅 하나만 요청한다.
> 2. **첫 두 줄에 상대 이름과 관찰이 들어간다.** 복붙 티가 나는 순간 삭제된다.
> 3. **후속 없이는 계약 없다.** 회신율의 절반은 D+4, D+10 후속에서 나온다.

---

## A. 콜드 메일 (대학교·기관·아파트·공공)

### 제목 — 열리는 제목의 공식: [기관명] + [구체 제안] + [부담 0]

- `[○○대학교 대동제] 야간 플리마켓 운영 제안 — 예산·인력 부담 없이`
- `○○아파트 주민 야시장 제안드립니다 (비용 0원, 운영 전담)`
- `[제안] ○○상점가 유동인구를 늘릴 주말 마켓 — 상인회 부담 없음`

> ✕ 나쁜 제목: "플릿 유니온 회사소개서", "행사 대행 제안의 건" — 스팸함 직행

### 본문

```
[[담당자님/학생회장님/소장님]] 안녕하세요,
플리마켓·야시장 운영 전문팀 플릿 유니온 [[이름]]입니다.

[[관찰 한 줄 — 예: 지난주 ○○대 축제 일정 공지를 봤는데, 저녁 시간대
프로그램이 무대 공연 외에는 비어 있더라고요.]]

저희는 그 시간과 공간을 [[야시장/플리마켓]]으로 채우는 일을 합니다.
[[기관명]]에서는 공간만 내어주시면 됩니다.

- 비용·인력 부담: 0 (기획·셀러 모집·장비·운영·철거 전액 저희 부담)
- [[기관명]] 몫: 부스 수익의 일부를 정산해 드립니다
- 경험: 대학교 축제 야시장, 캠퍼스 플리마켓, 아파트 단지 야시장 등
  50건 이상 운영

구체적인 그림을 담은 기획서를 첨부드립니다.
[[한 장 요약]]만 보셔도 구조가 바로 보이실 겁니다.

괜찮으시면 다음 주 중 30분만 시간 내주실 수 있을까요?
[[0일(0) 00시 / 0일(0) 00시]] 중 편하신 때, 또는 제가 맞추겠습니다.

플릿 유니온 [[이름]] 드림
[[010-0000-0000]] · https://flitunion.com
```

> 길이 상한: 스크롤 한 번. 이보다 길면 자른다.

## B. 인스타그램 DM (카페·애견카페·소상공인)

> DM은 메일보다 더 짧게. 기획서 파일을 바로 던지지 말고 **대화를 먼저 연다.**

### 1차 DM
```
안녕하세요 사장님! 플리마켓 운영팀 플릿 유니온입니다 🙂

[[매장 관찰 — 예: 마당이 진짜 넓어서 볼 때마다
'여기서 펫 마켓 하면 대박이겠다' 생각했어요.]]

저희가 [[펫 프리마켓/소품 마켓]] 셀러 모집부터 운영까지
전부 맡아서 하고, 사장님은 공간만 내어주시면 되는
구조로 행사를 만들고 있어요. (비용 부담 0원이에요)

[[비수기 평일/주말]] 하루, 매장에 새 손님들 채워드리는
그림인데 — 간단히 설명드려도 될까요?
```

### 관심 표시 시 2차
```
감사합니다! 간단히 구조만 말씀드리면:

1. 저희가 셀러 [[10~15]]팀 모집 (참가비는 저희가 수취)
2. 사장님 매장 [[야외/유휴]] 공간에 [[토요일 낮]] 하루 오픈
3. 방문객은 자연스럽게 매장 이용 → 음료 매출 + 신규 손님
4. 홍보는 저희 채널 + 셀러들 계정에서 동시에 나가요

사장님 부담은 0원이고, 원하시면 [[공간 사용료/매출 연계]]
방식도 가능해요. 자세한 건 기획서로 정리해 보내드릴게요.
편하신 이메일이나 카톡 있으실까요?
```

## C. 후속 연락 (모든 채널 공통)

### D+4 — 1차 후속 (가볍게, 가치 하나 추가)
```
[[담당자님]] 안녕하세요, 플릿 유니온 [[이름]]입니다.
지난주 보내드린 [[행사명]] 기획서 관련해 살짝 후속 드립니다.

생각해 보니 [[기관 맞춤 추가 아이디어 한 줄 — 예: 학생 창업팀을
우선 배정하면 총학 자체 프로그램으로도 소개하실 수 있겠더라고요.]]

바쁘신 줄 알기에, 검토에 필요한 자료가 있으면 언제든 말씀 주세요.
```

### D+10 — 2차 후속 (마감 장치)
```
[[담당자님]], 플릿 유니온 [[이름]]입니다.

[[행사 시즌]]까지 셀러 모집 기간([[4]]주)을 확보하려면
[[00월 00일]]경에는 방향이 정해져야 해서 마지막으로 연락드립니다.

이번에 어려우시면 [[다음 시즌]]에 다시 제안드리겠습니다.
한 줄 회신만 주셔도 감사하겠습니다.
```

### D+10 무응답 시
CRM(스프레드시트)에 `무응답-다음시즌` 표시 후 종료. 3통 이상 보내지 않는다.
다음 시즌 시작 전 새 관찰을 넣어 새 기획서로 다시 접근한다.

## D. 채널·타이밍 치트시트

| 타깃 | 채널 | 보내는 요일·시간 | 시즌 |
|---|---|---|---|
| 대학교 학생회 | 인스타 DM(학생회 계정) + 메일 | 화~목 11시 | 3월 초(5월 축제), 8월 말(9~10월 축제) |
| 대학 본부 | 대표 메일 → 유선 확인 | 화~목 오전 | 동일 |
| 상인회 | 유선 → 방문 → 서면 | 평일 14~16시(한가한 시간) | 상시, 지역행사 2달 전 |
| 아파트 입대의 | 관리사무소 유선 → 메일 | 평일 오전 | 정기회의 2주 전 |
| 학원 | 메일 + 유선 | 월·화 14시(수업 전) | 신학기 직전 (2월, 8월) |
| 공공시설 | 공문 메일 | 평일 오전 | 분기 초 |
| 카페·애견카페 | 인스타 DM | 평일 15~17시(브레이크) | 비수기 진입 1달 전 |
| 행사 기획사 | 메일 + 링크드인 | 화~목 | 상시 |

## E. 발송 관리 (미니 CRM)

스프레드시트 컬럼: `기관명 | 유형 | 담당자 | 채널 | 1차 발송일 | D+4 후속 | D+10 후속 | 상태(발송/열람/회신/미팅/계약/무응답) | 다음 액션 | 메모`

주간 루틴: **월요일 신규 발송 → 수요일 후속 → 금요일 상태 정리.** 주당 신규 10건이면 충분하다. 100건 복붙보다 10건 맞춤이 회신율이 높다.
