## 1. 한 장 요약

### 제안 한 줄
한빛대학교 중앙광장에 대동제 기간(10/14~16) 야시장을 기획·운영하여,
무대 공연 종료 후 비어 있던 저녁 시간대를 학생들이 머무는 콘텐츠로 채웁니다.

### 총학생회의 부담

| 항목 | 부담 |
|---|---|
| 비용 | **0원** (기획·모집·장비·운영·철거 전액 플릿 유니온) |
| 인력 | **0명** (전담 매니저 2인 상주) |
| 제공해 주실 것 | **중앙광장 사용 승인 + 야외 전기 사용 협조**, 끝 |

### 기대 효과
1. **저녁 콘텐츠 공백 해소** : 공연 종료(19시) 후에도 학생들이 캠퍼스에 머무는 이유가 생깁니다
2. **학생 창업팀 판매 기회** : 부스 30% 이상 교내 학생팀 우선 배정 — 총학 자체 프로그램으로 소개 가능
3. **학생회 수익** : 부스 참가비 수익의 **30%**를 총학생회에 정산 (예상 약 90만원)

### 요청사항
**30분 미팅 한 번** — 9/8(화) 14시 / 9/10(목) 16시 / 편하신 시간

## 3. 왜 중앙광장인가 (발췌)

### 공간을 이렇게 봤습니다
- 작년 대동제 에브리타임 후기에서 "공연 끝나면 갈 데가 없다"는 글이 반복적으로 올라왔습니다
- 중앙광장은 폭 약 25m × 길이 50m로, 양측 배치 시 부스 40개 + 중앙 통행로 8m 확보가 가능합니다
- 정문~기숙사 동선이 광장을 관통해, 별도 홍보 없이도 저녁 유동 인원이 지나갑니다

### 그래서 지금입니다
대동제 D-43. 이번 주 방향이 정해지면 셀러 모집 4주 + 학생팀 선발 기간을 온전히 확보합니다.
