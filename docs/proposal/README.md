# 플릿 유니온 영업 기획서 시스템

공간 보유자(대학교·상점가·아파트·학원·운동장·애견카페 등)에게 DM/메일로 보낼
기획서를 빠르게 찍어내기 위한 템플릿 모음입니다.

## 파일 구성

| 파일 | 언제 쓰나 |
|---|---|
| `01-기획서-마스터-템플릿.md` | 모든 기획서의 뼈대. 이걸 복사해서 `[[ ]]` 만 채운다 |
| `02-타깃별-변형가이드.md` | 대상이 정해지면 여기서 해당 섹션을 읽고 마스터를 수정 |
| `03-아웃리치-스크립트.md` | 기획서를 붙여 보낼 DM·메일 본문 + 후속 연락 |
| `04-사전-체크리스트.md` | 기획서 쓰기 전 반드시 확보할 정보 / 보내기 전 최종 점검 |

## 작업 순서

```
① 타깃 선정
   ↓
② 04-사전-체크리스트 로 정보 수집 (특히 "현장 관찰 1줄")
   ↓
③ 01-마스터-템플릿 복사 → [[ ]] 채우기
   ↓
④ 02-타깃별-변형가이드 로 3·5·8·9번 섹션 교체
   ↓
⑤ PDF 출력 (파일명: 플릿유니온_제안서_[[기관명]]_[[YYYYMMDD]].pdf)
   ↓
⑥ 03-아웃리치-스크립트 로 DM/메일 발송
   ↓
⑦ D+4 / D+10 후속 연락
```

## 절대 규칙 5가지

1. **1페이지 요약에서 "귀 기관 부담 0원"이 안 보이면 실패다.** 그 문장 하나로 미팅이 잡힌다.
2. **우리 자랑 대신 상대 이익으로 쓴다.** "Flit 셀러 500명 보유" → "셀러 모집에 담당자님 시간 0시간".
3. **요청사항은 딱 하나만.** 30분 미팅 또는 현장 답사. 두 개 요청하면 둘 다 안 된다.
4. **현장을 봤다는 증거를 3번 섹션에 반드시 넣는다.** 복붙 제안서와 갈리는 지점이 여기다.
5. **담당자가 무서워하는 것(민원·안전·허가·뒷정리)을 9번에서 먼저 죽인다.** 상대가 묻기 전에 답해야 신뢰가 생긴다.
